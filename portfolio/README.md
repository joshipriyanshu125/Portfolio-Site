# Priyanshu Joshi - Developer Portfolio

A responsive, WebGL-enhanced developer portfolio showcasing full-stack MERN work and an active Generative AI learning journey.

## Stack

- React 18 + Vite
- Three.js + React Three Fiber
- Framer Motion
- CSS design system with responsive and reduced-motion support

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Project structure

```text
src/
  assets/       Static design assets
  components/   Shared interface components
  data/         Portfolio content and social links
  three/        WebGL scene components
  App.jsx       Page composition
  styles.css    Responsive visual system
public/         Downloadable resume and public files
```

Edit `src/data/portfolio.js` to update personal details, projects, skills, and milestones without changing the interface.
